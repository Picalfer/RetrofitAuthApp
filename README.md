# Retrofit Auth App

[![Kotlin](https://img.shields.io/badge/Kotlin-1.8+-blue.svg?logo=kotlin)](https://kotlinlang.org)
[![Platform](https://img.shields.io/badge/Platform-Android-green.svg?logo=android)](https://www.android.com/)
[![Retrofit](https://img.shields.io/badge/Retrofit-2.9-orange.svg)](https://square.github.io/retrofit/)

Полноценное приложение для изучения Retrofit с аутентификацией в Android. Демонстрирует работу с API, навигацией и Shared ViewModel.

## Функциональность

- Аутентификация через API
- Поиск товаров с авторизацией
- Навигация между фрагментами
- Shared ViewModel для управления состоянием
- Логирование HTTP запросов
- Загрузка изображений с Picasso

## Технологии

- Kotlin
- Retrofit 2 + Gson
- OkHttp Logging Interceptor
- ViewModel + LiveData
- Navigation Component
- Picasso
- Coroutines
